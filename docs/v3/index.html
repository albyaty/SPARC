Single Port Advanced Research Consortium

SPARC is a multi-institutional research consortium studying single-port robotic surgery in urology. Participating centers contribute prospectively collected outcomes to a shared, IRB-approved registry coordinated at Cleveland Clinic.

How the registry works

Each participating institution enters prospectively collected outcomes into a shared REDCap database hosted at Cleveland Clinic. Members propose studies, which are run on the pooled data.

  • Local IRB approvalEvery site holds an active IRB at its home institution.
  • Data use agreementA data use agreement with the host institution governs each contribution.
  • Steering committee reviewProject proposals are vetted by the data host and steering committee.

Registry databases

Each database captures procedure-specific perioperative, oncologic, and functional outcomes.

      Joining SPARC

      Institutions performing single-port robotic urologic surgery can join by completing three steps.

      1. Active IRB at your home institutionApproval to contribute de-identified single-port outcomes.
      2. Data use agreement with the hostA fully executed DUA with Cleveland Clinic, the SPARC data host.
      3. Prospective data on REDCapOngoing case entry and follow-up on the shared registry.
