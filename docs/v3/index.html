How SPARC works

Every center contributes. One registry answers.

Participating institutions enter prospectively collected outcomes into a shared REDCap registry hosted at Cleveland Clinic. Pooled, the data answer questions about technique, safety, and patient selection at a scale no single program can reach.

  • Approved locallyEvery site holds an active IRB at its home institution.
  • Shared securelyA data use agreement with the host institution governs each contribution.
  • Reviewed centrallyProject proposals are vetted by the data host and steering committee.
The registry

Six procedure databases.

Each database captures procedure-specific perioperative, oncologic, and functional outcomes, from the prostate and kidney to the bladder and upper tract.
